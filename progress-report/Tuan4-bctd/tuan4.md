# Báo cáo tiến độ tuần 4

**Thời gian:** 02/11/2026 – 08/11/2026

## 1. Công việc thực hiện

- Thiết kế bản phác thảo giao diện trên Figma: Đăng nhập, Trang chủ, Quản lý bệnh nhân, Quản lý loại xét nghiệm, Tạo phiếu xét nghiệm.
- Xây dựng giao diện Web cơ bản bằng HTML, CSS và JavaScript.
- Xây dựng giao diện quản lý bệnh nhân, loại xét nghiệm và phiếu xét nghiệm.

## 2. Kết quả đạt được

- Hoàn thành bố cục chung và các trang giao diện cơ bản của hệ thống.
- Trang quản lý bệnh nhân có bảng danh sách, tìm kiếm và biểu mẫu thêm/sửa.
- Trang quản lý loại xét nghiệm hiển thị nhóm, chỉ số, đơn vị tính, khoảng tham chiếu mô phỏng và giá.
- Trang tạo phiếu xét nghiệm cho chọn bệnh nhân, chọn xét nghiệm và tính tổng tiền tạm tính.
- Dùng JavaScript kiểm tra dữ liệu nhập, tìm kiếm trên bảng và tính tổng tiền.
- Đã cập nhật mã nguồn giao diện và báo cáo tuần 4 lên GitHub.

## 3. Khó khăn

Tổ chức giao diện thống nhất giữa các trang và chuyển giao diện tĩnh sang các trang của ứng dụng .NET kết nối SQL Server còn gặp khó khăn.

## 4. Kế hoạch tuần tiếp theo

- Tạo project ứng dụng Web C#/.NET và kết nối cơ sở dữ liệu QLTTXNYK.
- Lập trình đăng nhập và phân quyền Quản lý/Nhân viên.
- Lập trình quản lý bệnh nhân, loại xét nghiệm, phiếu xét nghiệm và mẫu xét nghiệm.
